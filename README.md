This is a personal portfolio website built with React, Vite, and Tailwind CSS.

## Features

- **Modern & Responsive UI**: Built with React, Vite, and Tailwind CSS
- **Interactive Components**: Smooth animations with Framer Motion and modern glassmorphism design
- **Comprehensive Showcase**: Highlighting Full-Stack Java projects, Spring Boot REST APIs, microservices, and certifications
- **Dark Mode Aesthetic**: Dynamic glows, custom cards, and interactive tech stack icons

## Technologies Used

- **Frontend**: React 19, Tailwind CSS, Framer Motion, Lucide Icons, React Icons
- **Backend & Tools**: Java, Spring Boot, MySQL, Vite

## Getting Started

To run this project locally:

1. Clone the repository
2. Install dependencies: `npm install`
3. Start the development server: `npm run dev`
